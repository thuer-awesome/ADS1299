# Contributing

提交硬件、固件或测试结果时，请同时提供版本、板卡序列号、芯片批次、数据手册版本、仪器设置和原始证据路径。任何电源、时钟、SPI、RLD/BIAS 或 BLE 结论都必须在 `docs/01_datasheet_traceability.md` 中注明页码和证据等级。

不要提交未经授权的第三方数据手册副本；使用 `data/raw/manifest.csv` 记录文件名、版本、大小和 SHA-256。大文件使用 Git LFS，并避免把个人隐私、人体数据或蓝牙 MAC 地址直接提交到公共仓库。

硬件修改必须附带更新后的原理图/PCB 版本和 ERC/DRC 报告；固件修改必须附带寄存器回读、帧完整性或回归测试结果。没有实测证据的项目保持 `OPEN`。
