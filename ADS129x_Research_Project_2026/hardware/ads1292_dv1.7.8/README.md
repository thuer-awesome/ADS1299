# ADS1292 DV1.7.8 硬件索引

原始工作区：`E:\ADS1299\2022-09-26 ADS1292 DV1.7.8（调整）STM32L432+4404B 双通道`。

- `DEMO.SchDoc`：当前原理图
- `DEMO.PcbDoc`：当前 PCB
- `ADS1292 DV1.7.8.1.zip`：PCB 归档（内容需解压后校验哈希）
- `微信图片_*.png`：设计截图，仅作辅助证据

该记录（GBK 解码）包含三项：去掉蓝牙天线、旋转芯片方向、调整焊盘位置。它们会直接影响 BLE 射频 keepout、引脚方向核对和装配可制造性，必须在重新导出 PCB 3D/装配图后复查。

相关历史版本：`E:\ADS1299\2022-05-13 ADS1292 DV1.7.4 （样板）STM32L432+4404B 双通道`（原理图/PCB/ZIP）和 `E:\ADS1299\2022-06-17 STM32L432 1.1.6（发货固件）优化蓝牙，降功耗 配套 ADS1292 DV1.7`（完整 STM32L4 固件库）。历史版本只用于追溯，不替代 DV1.7.8 的网表审核。

本版本为 2 通道 ADS1292/1292R 符号，数据帧 9 byte，PWDN/RESET 共用一脚，典型 AVDD=3 V、DVDD=1.8 V、外部 CLK=512 kHz、VCAP1≈10 µF。`DEMO.SchDoc` 可读字符串含 `STM32L442KCU6`、`SPI1`、`SPI3` 和 `RF-BM-4044B4`，与目录名中的 STM32L432 及其他版本的 BG22A 模块不同；需以 PCB 装配、芯片顶标和 4044B4 手册确认后，再从 Altium 正式网络表补齐引脚映射。
